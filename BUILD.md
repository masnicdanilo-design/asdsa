# Build

1. `npm install`
2. Linux/macOS: `./buildPlugin.sh`   |   Windows: `.\buildPlugin.ps1`
   (potrebni: JDK, Android SDK, zip, python3 ili jq)
3. Rezultat: `build/outputs/app_shortcuts.snplg` -> kopiraj u MyStyle na Supernote
4. Settings > Apps > Plugins > Add Plugin
5. U DOC-u: toolbar dugme "App shortcuts" -> izaberi aplikacije -> Sačuvaj.
   Selektuj tekst: dugmad aplikacija su u context meniju.
